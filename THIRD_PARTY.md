# Credits, tools and originality statement

**Project:** AI-Driven Parametric Design and Multi-Tank Optimisation of Intze Elevated Water Tanks
**Author:** Zainab Nayeem (SMIT, AI&DS, enrolment 202300069)

## What is original work in this repository
All project code in `src/` was written for this project and is not copied from any other repository:
design engine (`intze_design_engine.py`, `wall_design.py`, `staging_design.py`, `foundation_design.py`, `wind_seismic.py`),
cost model, dataset generator, surrogate training, optimiser wrapper, adaptive re-optimiser, construction tracker,
regional planner, 3D visualisation script, validation script, and the Flask web app (`app.py`, `templates/`, `static/`).
The training data is synthetic, generated by this project's own design engine (`generate_dataset.py`).

## Engineering sources (formulas and rules, not code)
- IS 3370 (liquid-retaining structures), IS 456:2000 (reinforced concrete), IS 875 Part 3 (wind), IS 1893 Part 1 (seismic).
  Simplified static methods are used and the assumptions are logged in each design output.
- Literature: Saxena & Pathak (2024), Indian Journal of Engineering and Materials Sciences 31(5); Intze shape-optimisation
  papers (Univ. of Tabriz 2015; meta-heuristic study 2024); Deb et al. (2002), NSGA-II; Blank & Deb (2020), pymoo.
  Papers were read at abstract level so far.

## Inspiration (no code taken)
- The idea of an Intze design tool comes from a Visual Basic 5 program written earlier by the author's father.
  Its source code has not been used or seen in this project.
- The dark visual style of the web app follows a reference image of a website supplied by the author. No code or assets were copied.

## Honest limits
Costs are relative (illustrative), wind and seismic use simplified static methods, and the engine has not yet been
compared with the VB5 program or with a real project. This is a decision-support tool, not a replacement for a
licensed structural engineer.
